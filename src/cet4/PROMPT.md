你负责 List {LISTS}。每个 List 的输入是 `src/cet4/in/Lxx.tsv`，一行一个词，用 `§` 分隔 6 栏：

`编号§原表单词§原表释义§现成音标§候选例句§候选译文`

原表是别人录的四级词表，只有单词和中文释义，**质量参差**：有错字（recongnize、winkle、saleman、大副写成「大幅」）、释义错位（owing 那格填的是 striking 的意思、principal 填的是 principle 的意思）、漏词性、句末截断、标点乱（`vt,` `n ,` `adj，`）。现成音标是网站里别的书已有的（牛津英音为主），候选例句是《雅思词根+联想记忆》书上的例句和译文（已经标好 `**`）。你要把它整理成背单词网站能用的干净数据，**每一条都要真的读、真的核对**。

## 要写的

每个 List 写一个 `src/cet4/Lxx.tsv`（xx 和输入一样），**行数、顺序、编号和输入一模一样**，每行 7 栏，用 `§` 分隔：

`编号§单词§音标§释义§例句§译文§备注`

- **单词**：照抄原表（去掉首尾空格）。只有这几种情况改，备注 `改词形：原表作 xxx`：
  - 拼错了：`recongnize/ise` → recognize，`winkle`（释义是皱纹）→ wrinkle，`saleman` → salesman，`ridical` → radical。
  - 释义明显是另一个词的：照释义改成那个词（`refuge` 释义是「难民」→ refugee）。但**原表同一 List 或别的 List 里已经有那个词**时，不要改词，改释义（照这个词本身的意思写，备注 `改释义`）。
  - 两种拼法写在一起的（`favo(u)rite`、`analyze/analyse`、`centimeter/-tre`、`instal(l)`）：单词栏写一个美式常用拼法（favorite、analyze、centimeter、install、fulfill），释义最前面加 `（英 favourite）` 这样一个小括号。
- **音标**：现成音标不空时写 `=`（沿用）；它跟这个词对不上（比如你改了词形，或明显错了）就自己写对的，备注 `改音标`。现成音标是空的就自己写：**英音、牛津学习词典的写法**（ˈ ˌ ː ə ʊ，不加斜杠、方括号，如 `ˈkʌltɪveɪt` `ˈhæpən` `ˈɪntrəst`）。
- **释义**：卡片和选择题用。**内容照原表**，只整理格式、改错：
  - 格式：`n. 体系，系统；制度 vt. 使符合；使一致`。词性用 n. v. vt. vi. adj. adv. prep. conj. pron. num. art. int. 缩写、后面带点和一个空格；原表 `n/v` `n/vt` 写成 `n./v.`；不同词性之间一个空格；同一词性里沿用原表的「，」「；」，标点一律全角中文标点，去掉句末多余的逗号、空格。
  - 改错（备注 `改释义：原因`，一句话）：错字（大幅→大副、领土→领主）、错位成别的词的意思、漏了词性（`允许进入，承认` → 补 `n.`）、句末截断补完、明显不是这个词的义项删掉。其他内容不要动，也不要自己加义项。只动格式不用写备注。
- **例句 / 译文**：
  - 候选例句不空时先判断：句子里这个词用的是不是释义里的某个意思、句子本身通顺、适合四级学生读。合适就两栏都写 `=`（沿用，构建时自动换成候选那句）。不合适就自己写一句，备注 `换例句：原因`（例：用的是释义里没有的意思；句子太怪）。
  - 候选例句是空的就自己写一句（不用写备注）。自己写的句子：12–22 个词，自然的现代英语，周围的词不要比四级难；**这个词（或它的变形，如 identified、kids）在句子里恰好出现一次**，用释义里最常用的那个意思；语境要让人看得出词义。
  - 译文：自然的中文，**恰好加一处 `**…**`**，把对应这个词的中文括起来（2–6 个字，只括这个词的意思，不括否定、不括整个短语；例：operate「电梯坏了」→「电梯不**运转**了」）。
- **备注**：没改就空着（行尾是 `§`）。几项用 `；` 隔开。

任何一栏里都不能有 `§`、制表符、换行。

## 怎么做

- **每做 25 个词就马上用 Write / Edit 写进文件**（第一次 Write 前 25 行，后面每 25 行追加一次），不要攒一整个 List 再写（一次输出太长会全部丢掉）。一个 List 写完再做下一个。
- 写完一个文件查一下：`awk -F'§' 'NF!=7' 文件 | wc -l`（应为 0）、`wc -l` 和输入一样；译文栏不是 `=` 的恰好一对 `**`：`awk -F'§' '$6!="=" {n=gsub(/\*\*/,"",$6); if(n!=2) print NR}' 文件`；编号对得上：`diff <(awk -F'§' '{print $1}' 文件) <(awk -F'§' '{print $1}' 输入)`。
- 别的文件都不要动。
