# 给子代理的说明（第五十五次优化，四级词汇海豚版）

工作目录：/Users/liuyanao/Desktop/SAT2300词汇整理/sat2300-web

你负责 List {LISTS}。每个 List 的输入是 `src/cet4d/in/Lxx.tsv`，一行一个词，用 `§` 分隔 8 栏：

`编号§原表单词§原表释义§参考单词§参考音标§参考释义§参考例句§参考译文`

原表是《四级词汇教师-海豚版》，给老师出测验用的表，只有单词和中文释义，**质量参差**：有错字（「局支配地位」应为「居」、homosexua、proclaime、plumbling、futhermore）、两种拼法写在一起（memorize/ise、blond(e)、connection/-xion）、标点乱（半角逗号、`n.…/ v.…`、句末多余的「；」）、少数释义空着、个别释义可能错位成别的词的意思。

「参考」那几栏是网站里《四级词汇2022版》已经整理、核对过的同一个词（参考单词可能是美式拼法或改正后的写法）。没有参考的，参考单词和参考释义是空的，参考音标、例句是网站里别的书现成的（可能也空着）。你要把它整理成背单词网站能用的干净数据，**每一条都要真的读、真的核对**。

## 要写的

每个 List 写一个 `src/cet4d/Lxx.tsv`（xx 和输入一样），**行数、顺序、编号和输入一模一样**，每行 7 栏，用 `§` 分隔：

`编号§单词§音标§释义§例句§译文§备注`

- **单词**：照抄原表。只有这几种情况改，备注 `改词形：原表作 xxx`：
  - 拼错了：homosexua → homosexual，proclaime → proclaim，plumbling → plumbing，futhermore → furthermore。
  - 两种拼法写在一起的（memorize/ise、blond(e)、connection/-xion）：写一个美式常用拼法，释义最前面加 `（英 memorise）` 这样一个小括号（blond(e) 写 blond，加 `（也作 blonde）`）。
  - 只写了英式拼法的（rumour、harbour、favourite、analyse、millimetre、tyre……）是对的拼法，**照抄，不改**。
  - 释义明显是另一个词的：照释义改成那个词。但这个 List 或别的 List 里已经有那个词时，不改词，改释义。
- **音标**：参考音标对得上这个词就写 `=`（沿用）；对不上（改了词形、英式拼法读音不同、明显错了）或空着就自己写：**英音、牛津学习词典的写法**（ˈ ˌ ː ə ʊ，不加斜杠、方括号，如 `ˈkʌltɪveɪt`），对不上而改的备注 `改音标`。
- **释义**：卡片和选择题用。**内容照海豚版原表**，只整理格式、改错：
  - 格式：`n. 体系，系统；制度 vt. 使符合；使一致`。词性用 n. v. vt. vi. adj. adv. prep. conj. pron. num. art. int. 缩写、后面带点和一个空格；`n./v.` `n./vt.` 这样写；不同词性之间一个空格（去掉原表词性前的 `/` `;`）；同一词性里沿用原表的「，」「；」，标点一律全角中文标点（`…` 照旧），去掉句末多余的逗号、分号、空格。
  - **原表没写词性的要补上**（原表很多只写「真诚的，诚挚的」）：照意思和参考释义补，例 `adj. 真诚的，诚挚的`。只补词性、整理格式不用写备注。
  - 改错（备注 `改释义：原因`，一句话）：错字、错位成别的词的意思、明显不是这个词的义项删掉、句末截断补完。其他内容不要动，也不要自己加义项。
  - **原表释义空着的**：参考释义不空就写 `=`（沿用 2022 版那条），备注 `补释义：原表空着`；参考释义也空就自己写一条简短的四级常用释义（照上面的格式），备注 `补释义：原表空着`。
  - 整理完和参考释义一字不差的，可以直接写 `=`。
- **例句 / 译文**：
  - 参考例句不空时先判断：句子里这个词用的是不是**你写的释义**里的某个意思、句子通顺、适合四级学生读，而且**句子里出现的是这个单词（或它的变形）**——单词和参考单词拼法不同时（rumour 对 rumor、harbour 对 harbor），参考例句里是另一种拼法，就不能用 `=`，自己写一句（可以拿参考那句把拼法改过来）。合适就两栏都写 `=`。不合适就自己写，备注 `换例句：原因`。
  - 参考例句空着就自己写（不用写备注）。自己写的句子：12–22 个词，自然的现代英语，周围的词不要比四级难；**这个词（或它的变形）在句子里恰好出现一次**，用释义里最常用的那个意思；语境要让人看得出词义。
  - 译文：自然的中文，**恰好加一处 `**…**`**，把对应这个词的中文括起来（2–6 个字，只括这个词的意思）。
- **备注**：没改就空着（行尾是 `§`）。几项用 `；` 隔开。

任何一栏里都不能有 `§`、制表符、换行。

## 怎么做

- **每做 25 个词就马上用 Write / Edit 写进文件**（第一次 Write 前 25 行，后面每 25 行追加一次），不要攒一整个 List 再写（一次输出太长会全部丢掉）。一个 List 写完再做下一个。
- 写完一个文件查一下：`awk -F'§' 'NF!=7' 文件 | wc -l`（应为 0）、`wc -l` 和输入一样；译文栏不是 `=` 的恰好一对 `**`：`awk -F'§' '$6!="=" {n=gsub(/\*\*/,"",$6); if(n!=2) print NR}' 文件`；编号对得上：`diff <(awk -F'§' '{print $1}' 文件) <(awk -F'§' '{print $1}' 输入)`；最后跑 `python3 src/build_cet4d.py --check`，你负责的 List 不能有报错（别的 List 的报错不用管）。
- 别的文件都不要动。
