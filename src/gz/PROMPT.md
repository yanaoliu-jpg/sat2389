# 给子代理的说明（第五十九次优化，新版高中词汇）

工作目录：/Users/liuyanao/Desktop/SAT2300词汇整理/sat2300-web

你负责 List {LISTS}。每个 List 的输入是 `src/gz/in/Lxx.tsv`，一行一个词，用 `§` 分隔 8 栏：

`编号§原表单词§原表释义§参考单词§参考音标§参考释义§参考例句§参考译文`

原表是《新版高中词汇》，一张 Sheet 一个 List，只有单词和中文释义。原表录得比较认真，释义大都带词性，但写法不统一：
`a.` `ad.` 这样的旧缩写、两个空格隔开不同词性、半角标点混着全角、`[U]` `[C]` `[pl.]` 可数不可数标记、`<口语>` `<总称>` 尖括号、
`(felt, felt, feeling)` 不规则变化，还有少数拼错的词（disguisting、ture）和打错的缩写（cong.、ept.）。

「参考」那几栏是网站里《四级词汇2022版》或《四级词汇海豚版》已经整理、核对过的同一个词（参考单词可能是美式拼法）。大约一半的词有参考。
没有参考的，参考单词和参考释义是空的，参考音标、例句是网站里别的书现成的（可能也空着）。高中词里很多是很基础的词（sure、feel、take、of……），四级书里没收，要你自己写。
你要把它整理成背单词网站能用的干净数据，**每一条都要真的读、真的核对**。

## 要写的

每个 List 写一个 `src/gz/Lxx.tsv`（xx 和输入一样），**行数、顺序、编号和输入一模一样**，每行 7 栏，用 `§` 分隔：

`编号§单词§音标§释义§例句§译文§备注`

- **单词**：照抄原表。只有这几种情况改，备注 `改词形：原表作 xxx`：
  - 拼错了：disguisting → disgusting，ture → true（看释义确认）。
  - 写成 `eastward(s)` `afterward(s)` `toward(s)` 的：写不带 s 的那个（eastward），释义最前面加 `（也作 eastwards）`。
  - 原表的英式拼法（neighbour、cosy、skilful、sceptical、programme、jewellery、cheque、practise、realise……）是这本书的写法，**照抄，不改**；原表释义前已经有的 `（美 neighbor）` 照留。原表反过来写美式词、括号里只写英式的（license 释义作 `(licence) n. …`），写成 `（英 licence） n. …`。
  - 同一个词出现两次的（List 4 的 can：一条情态动词，一条名词「罐头」）是两个词条，各写各的，例句用各自的意思。
- **音标**：参考音标对得上这个词就写 `=`（沿用）；对不上（参考单词拼法不同、读音不同、明显错了）或空着就自己写：**英音、牛津学习词典的写法**（ˈ ˌ ː ə ʊ，不加斜杠、方括号，如 `ˈkʌltɪveɪt`）。短语（used to、chain store）写整个短语的音标，词之间一个空格。对不上而改的备注 `改音标`。
- **释义**：卡片和选择题用。**内容照这本书的原表**，只整理格式、改错：
  - 词性统一成：n. v. vt. vi. adj. adv. prep. conj. pron. num. art. int. aux. 和 `modal v.` `link v.`，后面带点和一个空格；`a.` 写成 `adj.`、`ad.` 写成 `adv.`、`link. v.` 写成 `link v.`、`cong.` 是 `conj.`、`ept.` 看意思改对；`n./v.` `adj./adv.` 这样合写的照留（缩写照上面换）。
  - 不同词性之间一个空格（原表是两个空格）；同一词性里沿用原表的「，」「；」，标点一律全角中文标点（`…` 照旧），去掉句末多余的逗号、分号、空格。
  - `[U]` `[C]` `[C, U]` `[pl.]` `[sing.]` 照留（方括号半角，紧跟在词性后面，如 `n. [U] 福利；安宁，幸福`）；`<口语>` `<总称>` 改成全角小括号 `（口语）` `（总称）`；不规则变化 `(felt, felt, feeling)` 改成全角括号照留：`v. （felt, felt, feeling）感觉；摸`。
  - 原表没写词性的（chain store「连锁店」）照意思补上，例 `n. 连锁店`。只补词性、整理格式不用写备注。
  - 改错（备注 `改释义：原因`，一句话）：错字、明显不是这个词的义项删掉、句末截断补完。其他内容不要动，也不要自己加义项。
  - 整理完和参考释义一字不差的，可以直接写 `=`；一般不会一样，照原表写就是。
- **例句 / 译文**：
  - 参考例句不空时先判断：句子里这个词用的是不是**你写的释义**里的某个意思、句子通顺、适合高中生读，而且**句子里出现的是这个单词（或它的变形）**——单词和参考单词拼法不同时（neighbour 对 neighbor、behaviour 对 behavior），参考例句里是另一种拼法，就不能用 `=`，自己写一句（可以拿参考那句把拼法改成英式）。合适就两栏都写 `=`。不合适就自己写，备注 `换例句：原因`。
  - 参考例句空着就自己写（不用写备注）。自己写的句子：10–20 个词，自然的现代英语，周围的词不要比高中难；**这个词（或它的变形）在句子里恰好出现一次**，用释义里最常用的那个意思；语境要让人看得出词义。of、the、but 这种功能词也要写一句能看出这个用法的例句。英式拼法的词，句子里也用这个英式拼法。
  - 译文：自然的中文，**恰好加一处 `**…**`**，把对应这个词的中文括起来（1–6 个字，只括这个词的意思）。功能词（of、than、at……）实在没有对应的字，就括最贴近它的那一两个字（「比」「在」）。
- **备注**：没改就空着（行尾是 `§`）。几项用 `；` 隔开。

任何一栏里都不能有 `§`、制表符、换行。

## 怎么做

- **每做 20 个词就马上用 Write / Edit 写进文件**（第一次 Write 前 20 行，后面每 20 行追加一次），不要攒一整个 List 再写（一次输出太长会全部丢掉）。一个 List 写完再做下一个。
- 写完一个文件查一下：`awk -F'§' 'NF!=7' 文件 | wc -l`（应为 0）、`wc -l` 和输入一样；译文栏不是 `=` 的恰好一对 `**`：`awk -F'§' '$6!="=" {n=gsub(/\*\*/,"",$6); if(n!=2) print NR}' 文件`；编号对得上：`diff <(awk -F'§' '{print $1}' 文件) <(awk -F'§' '{print $1}' 输入)`；最后跑 `python3 src/build_gz.py --check`，你负责的 List 不能有报错（别的 List 的报错不用管）。
- 别的文件都不要动。
