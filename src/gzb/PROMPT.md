`a.` `ad.` 旧缩写、`VI.` 大写、词性和中文之间有的有空格有的没有、`n 结果` 漏了点；半角 `, ; :` 混着全角，还有把「；」打成「:」的（`名誉:尊敬`）；
`【同 only】` `【反dead】` 同义 / 反义注写法不统一，里面有断行连字符（`terri-ble`、`op-erate`）和错词（`【反clam】` 应是 calm）；
`【pl.】` `【the】` `[pl]` `Ithe~]` 这类标记；`a.1公平的…；2金发的…` 带序号；还有串行、截断的（simple 后面接了 least 的「最不重要的 ad.最少，最小」）。

「参考」那几栏是网站里已经整理、核对过的同一个词：先找《新版高中词汇》，再找《四级词汇2022版》《四级词汇海豚版》（参考单词可能是另一种拼法）。
1469 个词里 1369 个有参考。没有参考的，参考单词和参考释义是空的，参考音标、例句是网站里别的书现成的（可能也空着），要你自己写。
你要把它整理成背单词网站能用的干净数据，**每一条都要真的读、真的核对**。

## 要写的

每课写一个 `src/gzb/Lxx.tsv`（xx 和输入一样），**行数、顺序、编号和输入一模一样**，每行 7 栏，用 `§` 分隔：

`编号§单词§音标§释义§例句§译文§备注`

- **单词**：照抄原表。只有这几种情况改，备注 `改词形：原表作 xxx`：
  - 原表写成两种拼法 `英式;美式` 的（apologise;apologize、favour;favor、programme;program、licence;license……）：单词写**分号前面那个**（这本书的写法），释义最前面加 `（美 apologize）`。
    `inquiry;enquiry` 写 inquiry、释义前加 `（英 enquiry）`；`examination;exam`、`dormitory;dorm`、`advertisement;ad` 写前一个，释义前加 `（也作 exam）` 这样；
    `humourous;humorous` 写 humorous（英式也是这个拼法），备注 `改词形：原表作 humourous;humorous`，它的释义原表写「幽默感」是名词义，改成「幽默的」。
  - 拼错了（看释义确认）改对。
  - 同一个词出现两次：preference 在 Lesson 2（n. 偏爱）和 Lesson 8（`v.更喜欢,宁愿`）。Lesson 8 那条释义是 prefer 的，前后是 serve/service/reserve/reservation，**改成 prefer**（备注 `改词形：原表作 preference，释义是 prefer 的`），释义照原表。别的重复照这个思路判断，真是两个词条就各写各的。
  - 其余英式拼法（neighbour、colour、centre……）是这本书的写法，**照抄，不改**。
- **音标**：参考音标对得上这个词就写 `=`（沿用）；对不上（参考单词拼法不同、读音不同、明显错了）或空着就自己写：**英音、牛津学习词典的写法**（ˈ ˌ ː ə ʊ，不加斜杠、方括号，如 `ˈkʌltɪveɪt`）。短语写整个短语的音标，词之间一个空格。对不上而改的备注 `改音标`。
- **释义**：卡片和选择题用。**内容照这本书的原表**，只整理格式、改错：
  - 词性统一成：n. v. vt. vi. adj. adv. prep. conj. pron. num. art. int. aux. 和 `modal v.` `link v.`，后面带点和一个空格；`a.` 写成 `adj.`、`ad.` 写成 `adv.`、`VI.` 写成 `vi.`、漏了点的补上；`n./vt.` `vi./n.` 这样合写的照留（缩写照上面换）。
  - 不同词性之间一个空格；同一词性里沿用原表的「，」「；」，**标点一律全角中文标点**（半角 `,` → `，`，半角 `;` → `；`，把「；」打成 `:` 的改回 `；`，`…` `……` 照旧），去掉句末多余的逗号、分号、空格。序号 `1公平的…；2金发的…` 去掉序号，义项之间用「；」。
  - 同义 / 反义注是这本书的特色，**照留**，统一写成 `【同 only】` `【反 dead】`（全角方头括号，「同」「反」后一个空格，几个词用全角「，」隔开），紧跟在它注的那个义项后面；里面的错改对（`terri-ble` → terrible，`【反clam】` → `【反 calm】`，former 的 `【同precious】` → `【同 previous】`），这类改错要写备注 `改释义：原因`。
  - 其它方头括号标记改成网站的写法：`【pl.】` `[pl]` → `[pl.]`，`【the】` `[the ~]` `Ithe~]` → `[the ~]`，`[a~]` → `[a ~]`（方括号半角，紧跟在词性后面或它注的义项前面，如 `n. 花费；[pl.] 开支`）；`【只用在名词前】` `【没有比较级】` `【也做Nature】` 这种说明改成全角小括号 `（只用在名词前）` `（也作 Nature）`；`<口语>` 改成 `（口语）`；半角小括号 `(on)` `(体力)` 改成全角 `（on）` `（体力）`。
  - 原表没写词性的照意思补上（`n 结果` → `n. 结果`，least `【Little的最高级】；最重要的…` 整理成 `adj. （little 的最高级）最少的；最小的 adv. 最少，最小` 这类，按词的实际用法）。只补词性、整理格式不用写备注。
  - 改错（备注 `改释义：原因`，一句话）：错字、明显不是这个词的义项删掉（串行串进来的别的词的意思）、截断的补完、断行（`体\n重`）接上。其他内容不要动，也不要自己加义项。
  - 整理完和参考释义一字不差的，可以直接写 `=`；一般不会一样，照原表写就是。
- **例句 / 译文**：
  - 参考例句不空时先判断：句子里这个词用的是不是**你写的释义**里的某个意思、句子通顺、适合高中生读，而且**句子里出现的是这个单词（或它的变形）**——单词和参考单词拼法不同时（apologise 对 apologize、examination 对 exam），参考例句里是另一种拼法，就不能用 `=`，自己写一句（可以拿参考那句改成这个拼法）。合适就两栏都写 `=`。不合适就自己写，备注 `换例句：原因`。
  - 参考例句空着就自己写（不用写备注）。自己写的句子：10–20 个词，自然的现代英语，周围的词不要比高中难；**这个词（或它的变形）在句子里恰好出现一次**，用释义里最常用的那个意思；语境要让人看得出词义。英式拼法的词，句子里也用这个英式拼法。
  - 译文：自然的中文，**恰好加一处 `**…**`**，把对应这个词的中文括起来（1–6 个字，只括这个词的意思）。
- **备注**：没改就空着（行尾是 `§`）。几项用 `；` 隔开。

任何一栏里都不能有 `§`、制表符、换行。

## 怎么做

- **每做 20 个词就马上用 Write / Edit 写进文件**（第一次 Write 前 20 行，后面每 20 行追加一次），不要攒一整课再写（一次输出太长会全部丢掉）。一课写完再做下一课。
- 写完一个文件查一下：`awk -F'§' 'NF!=7' 文件 | wc -l`（应为 0）、`wc -l` 和输入一样；译文栏不是 `=` 的恰好一对 `**`：`awk -F'§' '$6!="=" {n=gsub(/\*\*/,"",$6); if(n!=2) print NR}' 文件`；编号对得上：`diff <(awk -F'§' '{print $1}' 文件) <(awk -F'§' '{print $1}' 输入)`；最后跑 `python3 src/build_gzb.py --check`，你负责的课不能有报错（别的课的报错不用管）。
- 脚本（如果要写）放在你自己的 scratchpad 里，不要放进项目。别的文件都不要动。
