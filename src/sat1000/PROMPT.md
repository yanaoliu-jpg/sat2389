# 给子代理的说明（第四十九次优化，SAT 冲刺终极 1000 真题词）

工作目录：/Users/liuyanao/Desktop/SAT2300词汇整理/sat2300-web

你负责 Unit {UNITS}。每个 Unit 的输入是 `src/sat1000/in/Uxx.jsonl`，一行一个词条（JSON），共 50 行，有：编号、单词、音标、词性、义项（`[构词]` `[辨析]` `[词族]` 开头的是那一类说明，`(引申义)` 是引申出来的意思）、搭配说明、易误读警示、例句（1–2 句，英文是 SAT 真题原句，`原书高亮` 是原书在句子里标出的那段，`补充语境` 为 true 的是第二句）。

这是别人整理的资料，**质量参差**：中文翻译有的和英文对不上（比如 complication 那句英文讲送货机器人，译文却写成无人机、括号里的内容也是另一句的），补充语境有的根本不含这个词，搭配说明有的写坏了（`complication ≠ complication 与 complexity`、`deviate ≠ deviate to`），义项有的夹着长篇解释。你的活是把它整理成背单词网站能用的干净数据，**每一条都要真的读、真的核对**。

## 要写的

每个 Unit 写一个 `src/sat1000/Uxx.tsv`（xx 和输入一样），**50 行，顺序、编号、单词和输入一模一样**，每行 12 栏，用 `§` 分隔：

`编号§单词§音标§释义§例句§译文§例句2§译文2§构词§搭配§辨析§备注`

- **音标**：照抄输入。只有明显错了才改（英式，ˈ ˌ ː，不加斜杠），备注 `改音标：原因`。
- **释义**：背单词卡片和选择题用的简短中文释义。格式 `v. 迫使；强迫；使信服` —— 词性用 n. v. adj. adv. conj. prep. 缩写，多个词性就 `adj. 现代主义的 n. 现代主义者`（词性之间一个空格）。从义项里提炼：保留每个真实义项的核心意思和必要的小括号限定（如「（艺术、建筑）」），去掉英文搭配举例、「真题中……」「与 X 并置时……」这类解释（有用的挪到「辨析」）。一般 8–35 个汉字，不要超过 45 个。`(引申义)` 的义项也要收进来。
- **例句**：输入第一句（不是补充语境的那句）英文**原样照抄**，一个字符都不改（弯引号 ’ “ ” 也照抄）。只有明显的录入错误（比如 `et al.analyzed` 漏了空格、拼写错）才改，备注 `改例句：原因`。
- **译文**：输入第一句的中文。先**逐句核对它和英文是不是同一个意思**：对得上就原样照抄；整句或部分对不上（译的是别的句子、漏译、错译）就按英文重新翻译或改对，改得越少越好，备注 `改译文：原因`。输入中文里破折号后面那种「——正是……」的解题评论，不是翻译，删掉（备注 `删评论`）。然后**恰好加一处 `**…**`**，把对应这个词的中文括起来（2–6 个字，只括这个词的意思，不括否定、不括整个短语；句子里用的是变形或派生词，如 deviation、compelling，就括它对应的中文）。
- **例句2 / 译文2**：输入的补充语境那句。**句子里必须真的出现这个词或它的派生/变形**（compel → compelling 算；完全没有就是放错了，两栏都留空，备注 `删例句2：不含本词`）。核对规则和第一句一样（英文照抄、译文核对改错、删评论、恰好一处 `**…**`）。输入中文是空的就自己翻译，备注 `补译文2`。没有补充语境就两栏都空。
- **构词**：义项里 `[构词]` 那条照抄（可以去掉多余空格），没有就空。`[词族]` 那条也放这里。
- **搭配**：从「搭配说明」整理，多条用 `；` 隔开，每条 `英文 中文意思`，比如 `compelling adj. 引人入胜的；令人信服的；compulsory adj. 强制的`。写坏的（自己和自己比、看不懂的）修好或删掉；`A ≠ B` 那种辨析性的挪到「辨析」。保留「真题 18 次全为此形」这类有用的小注，放在那条后面的括号里。没有就空。
- **辨析**：义项里 `[辨析]` 那条 + 易误读警示 + 从释义、搭配挪过来的有用说明，合成一两句话，用 `；` 隔开，精炼，总共不超过 120 个汉字。没有就空。
- **原书义项、搭配、辨析本身有错**（意思解释错、词性标错、英文拼错）：照对的写，备注 `原书错：哪里错、怎么错`（一句话）。
- **备注**：没改动就空着（行尾是 `§`）。几项用 `；` 隔开。

任何一栏里都不能有 `§`、制表符、换行。英文栏里照抄原文的标点。

## 怎么做

- **每做 25 个词就马上用 Write / Edit 写进文件**（第一次 Write 前 25 行，再把后 25 行追加上），不要攒一整个 Unit 再写（一次输出太长会全部丢掉）。一个 Unit 写完再做下一个。
- 写完一个文件，用 `awk -F'§' 'NF!=12' 文件 | wc -l`（应为 0）和 `wc -l`（应为 50）查一下；再查每行译文那栏（第 6 栏）恰好有一对 `**`：`awk -F'§' '{n=gsub(/\*\*/,"",$6); if(n!=2) print NR}' 文件`；例句2 不空的，第 8 栏也一样。
- 别的文件都不要动。
